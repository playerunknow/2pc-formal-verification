# tools/

Тут лежать інструменти верифікації. **У git їх немає** — вони завантажуються скриптом:

```bash
python scripts/setup_tools.py
```

| Файл / папка | Інструмент | Версія | Навіщо |
|---|---|---|---|
| `tla2tools.jar` | TLC (TLA+ Tools) | реліз `v1.8.0` | перебір усіх станів моделі |
| `apalache/` | Apalache | `v0.50.3` | символьна перевірка індуктивного інваріанта (SMT, Z3) |
| `plantuml.jar` | PlantUML | `1.2024.8` | рендер діаграм `.puml` у PNG/SVG |

Потрібна лише Java 17+ як рантайм. Знати Java не потрібно.
Перезавантажити все: `python scripts/setup_tools.py --force`.
